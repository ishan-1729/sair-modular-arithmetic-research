# SAIR Modular Arithmetic Knowledge Bundle

This bundle is the human- and agent-readable control plane for the project. It follows Open Knowledge Format v0.1: concept documents are Markdown with YAML frontmatter, directories expose progressive-disclosure indexes, normal Markdown links form the knowledge graph, and `log.md` records material changes.

## Navigate

- [Competition](competition/) — task contract, evaluation, compliance boundary, and rule ambiguities.
- [Research](research/) — evidence synthesis, alternative approaches, and standards comparison.
- [Planning](planning/) — roadmap, experiment program, and risk register.
- [Data](data/) — benchmark Data Card and data lifecycle policy.
- [Evaluations](evals/) — metric contract, validation gates, and result interpretation.
- [POCs](pocs/) — model cards and proof-of-concept status.
- [Submission candidates](submissions/) — promoted official-interface artifacts and release state.
- [Decisions](decisions/) — architectural decision records.
- [Runbooks](runbooks/) — exact reproduction and release procedures.
- [Autoresearch](autoresearch/) — persistent Principal ML experiment, tracking, and promotion contract.
- [Bundle log](log.md) — chronological knowledge updates.

## Scope boundary

Only this directory is a strict OKF bundle. Code, JSON/YAML configuration, JSONL datasets, binary weights, and machine-readable result files remain in their native formats elsewhere in the repository and are linked from concepts here.
