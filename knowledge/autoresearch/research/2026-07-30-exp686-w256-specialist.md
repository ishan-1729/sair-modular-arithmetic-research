# EXP686 W256 learner-state straight-through mechanism map

Candidate005 predicts each radix-2 transition with a shared dilated ConvGRU. EXP686 keeps
that model, checkpoint, supervision target, optimizer step count, batch sampler and eight
unrolled calls fixed. The intervention is restricted to the state passed between calls.
The learner-exposed arm uses a hard sigmoid decision in the forward pass and the sigmoid
probability's gradient in the backward pass; the matched teacher-forced arm substitutes
the exact previous state. Thus any admitted formal difference would be attributable to
state exposure rather than examples, compute calls, parameter count or optimizer work.

The tensor-native cache is an execution optimization, not a model intervention. Calibration
requires exact output and minimum-margin equality against the legacy W256 route. The full
candidate-shaped timing path preserves Candidate005 routing for widths <=128, uses only
learned specialist weights for widths 129-256, and applies the already frozen zero fallback
above 256. Exact arithmetic remains limited to offline labels, tests, and sanctioned input
reduction; timed inference cannot inspect labels or answers.

Root 20261294 verified all of those mechanism and integrity claims. Both trained arms ran
four calibration updates, 512 examples and 32 supervision calls, with identical initial
state hash `3f0a441f...3f10`; their reloaded checkpoints differ as expected. Frozen/reset weights
retain the source hash, while the randomized control does not. Tiny 2-case rollouts are
explicitly non-scientific.

The package parks solely because measured variability converts 220.102 seconds for the
complete 1,100-case candidate route into a guarded 398.966 seconds, exceeding 285. Formal
root 20261295 and confirmation roots remain unopened, so exposure-bias causality and W256
accuracy remain scientifically unresolved.
