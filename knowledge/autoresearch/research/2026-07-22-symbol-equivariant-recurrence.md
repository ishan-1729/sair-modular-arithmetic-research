# Symbol-equivariant recurrence translation

## Fresh formal successor

EXP-660 preserves the bounded-faithful EXP-659 architecture and controls but
uses the still-unused formal seed `20261177`, fresh ordinary initialization and
a newly confirmed dynamic resource budget. It is the decision-producing
successor after EXP-659 was parked before science by an inherited project-oracle
provenance failure. The formulation remains explicitly bounded-faithful: exact
equivariance applies only inside the learned symbol-axis core, while the binary
arithmetic boundary is anchored and the legal task domain is not closed under
global zero/one complementation.

The complete 18-page local paper `arxiv-2603.02193.pdf` was read before the
EXP-659 preregistration was frozen. Its transferable mechanism is the explicit
symbol axis and alternating position/symbol self-attention of §2.3, Equations
9–11 (pages 5–6), with Proposition 2.3's permutation-equivariant recurrent
core. The task embedding uses a shared usual-symbol vector, while prediction
maps each symbol token to one logit. The source also explicitly demonstrates
that equivariance is domain-dependent: it is broken for Maze (page 8), and the
Appendix A7 ablation (page 18) shows that forced equivariance helps Sudoku but
harms Maze.

For modular arithmetic, complementing every binary symbol does not preserve the
legal prime-modulus input domain and does not preserve the transition labels.
Therefore EXP-659 tests core equivariance, not a false end-to-end bit-swap
claim. Learned semantic anchors are confined to the arithmetic boundary. The
faithful core remains tied across the two symbol slots; the causal control adds
symbol-indexed affine parameters inside the core. This matches the normative
M015.a ledger and keeps M015.b operand commutativity separate.

The paper's reported data scale, 2M parameter count, and task-specific halting
choices are source observations, not copied budgets. EXP-659 uses a small CPU
falsifier, fixed recurrent depth, matched fresh data, measured dynamic budgets,
and exact autonomous rollouts. Its terminal verdict applies only to this frozen
translation.
